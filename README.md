## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (`>= 3.22.0`)
- [Dart SDK](https://dart.dev/get-dart) (`>= 3.4.0`)
- A [Supabase](https://supabase.com/) project instance

### 1. Clone the Repository

```bash
git clone [https://github.com/your-username/climb-app.git](https://github.com/mifdirfan/climb-app.git)
cd climb-app
```

### 2. Configure Environment Variables
Create a .env file in the project root:

```bash
SUPABASE_URL=[https://your-project-id.supabase.co](https://your-project-id.supabase.co)
SUPABASE_ANON_KEY=your-supabase-anon-key
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application
Run according to your platform

```bash
flutter run -d chrome
flutter run -d android
flutter run -d ios
```
